## 目录说明

- `系统分析与设计文档/`：当前设计报告，包含概述、目录、项目愿景、业务建模、需求、类与状态分析、数据库和开发约束。
- `图片合集/`：按业务模型、类图、数据库 ER 图及完整总图分类保存，共67组PNG和SVG文件。
- `PlantUML图源/`：与图片对应的可编辑 `.puml` 文件。

患者服务系统与诊所管理系统分别提供入口，共享受权限控制的后台数据。数据库设计包含34张表、270个字段和69条外键；分析类与数据库按业务语义映射，不要求逐类建表。

案例以匿名化就诊经历为基础，结合公开资料分析问题；文档中的改进目标与验收条件属于设计要求，不代表系统已上线或已取得实际经营效果。
