# Open Dental 参考方案审定
日期：2026-10-23。只审定方向，不表示实现或课件符合性验收。以本项目已审定规格优先，不改代码/迁移/Word。

1. 首期不新增表。取消后重新安排作为预约工作台实施时的候选需求，不立即修改接口。必须患者明确请求回访或有可核实的人工协调依据才进入待办；不能所有已取消预约自动进入，更不能因取消自动推断医疗需要。需支持已联系、拒绝回访、已自行重约、无法联系、无需继续的关闭/暂缓结果。复用appointment/contact_record前先核对现有字段和枚举是否能无歧义表示，不以“肯定不用改字段”为前提。不能仅用previous_id有后继判断关闭，患者自主新建预约未必有previous_id；也不能同患者有任何预约就关闭。未预约复诊先维持首期已有只读边界，诊疗写入后再完善。
2. 治疗计划：确认作为后续有价值能力，尤其正畸跨次治疗；当前不批准候选表DDL。计划项目可能跨多次实际治疗，不能将plan_item到care_item固定0..1；后续根据治疗次数与收费单位审定关系。报价接受不等于已实施，不自动开账单。
3. 外加工：后续优先候选，先评估复用supplier作为供方身份，避免另建重复实验室主档；只有专属资格/能力信息才考虑扩展表。加工件应追溯患者、治疗/方案、门店及返工历史，预约仅可选关联；费用不能重复进入耗材和经营费用。未批准立即加表。
4. 收款：首版维持一笔收款归属一张账单，支持同账单分次收款。跨账单分摊需确认需求再加，不能为仿照paysplit提前扩张。退款、发票、应收与实收的独立关系保留。
5. 候补：后续可选，仅人工候选+明确同意，再走正常预约竞争校验；不预占、不自动加号、不保证通知后仍有空位。

更正分析措辞：XML未见某字段不等于整个产品没有该能力；不使用“Open Dental成本更浅”等产品完整性结论。48表/60表及字段数量仅为阶段基线，V004等迁移会改变字段总数，不是完成度。外部XML的FK说明先当逻辑引用，未核实DDL不声称物理约束。

课件/PPT尚未定位，嵌入图未逐张目视，因此不可宣称全面符合课件。已完成的是业务差距方向审定，后续实施时仍逐项核对。T021-A独立验收继续另行处理，不被本审定代替。
