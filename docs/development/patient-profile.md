# 本人资料读取与修改

2026-11-11 接通 `GET/POST /me/profile` 与小程序“个人信息”。患者 Bearer 只能读取、修改其账号绑定的 patient 行；员工 Cookie 不可调用。姓名、生日、主治医生均为只读事实，更正须走人工核验，不让客户端直接重设主治。

更新要求 `Idempotency-Key` 和 `expected_version`。联系方式未提供则沿用当前值，提供空字符串可清空可选联系方式；电话不能清空。过敏状态为「有 / 不确定」时本次必须填写说明；改为其他状态时清空当前说明。更新只改当前 patient 行，不重写既有 `visit_record` 的过敏快照。同键重放再次验证本人身份并返回当前权威资料；不同内容复用同键和过期版本分别返回 409。

小程序页面只在 `/auth/me` 核验后读取资料，身份切换或页面隐藏使旧请求失效。网络结果不明时保留表单和同键，不自行宣称保存成功；用户可刷新权威资料或用原内容重试。

真实隔离 PostgreSQL HTTP 测试覆盖本人隔离、必填说明、更新、同键重放、版本冲突和未知字段。小程序类型检查和 API 单测通过。微信开发者工具 WXML/WXSS 编译与真机操作仍需另行验收。
