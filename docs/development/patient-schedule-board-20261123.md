# 患者端按项目查看排班（2026-11-23）

医生页的真实排班改为“项目在左，日期和班次在右”。患者登录后选择儿童检查、补牙等实际可约项目，右侧按日期分上午、下午或全天，列出完整排班时间、医生、门店及是否有可约时段。点击“选择时段”会把门店和项目带入既有真实预约流程；最终可约时段和提交结果仍由后端确认。

数据只从 `/me/booking` 返回的 `schedules`、`services` 和 `availability` 联合派生。没有关联项目的班次不显示，`slots=[]` 显示“暂无可约时段”，不写“已满”或虚构剩余号数。某半天没有该项目班次时显示“无排班”。真实预约仍按“门店→项目→日期/时段→确认”办理；公开医生名录保留在排班下方供浏览和收藏。

切换账号或退出登录会清空旧项目和排班；请求代次校验仍防止旧响应回填。演示模式继续只显示本地虚构医生资料，与真实排班分离。
