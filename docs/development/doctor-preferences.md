# 医生收藏与来源（FR-004）

2026-11-11 实现。本人以患者小程序会话读取、收藏、修改来源和取消收藏，接口沿用 `contracts/openapi.yaml` 中 `/me/doctor-preferences` 的 GET、PUT、DELETE；没有新增迁移，复用 `doctor_preference`。

- 收藏来源限「本人选择 / 熟人推荐 / 既往就诊」，表示用户选择来源，不证明转诊事实，不存推荐人姓名或病历，也不改变长期主治、排班或预约医生。
- 写入时只接受当前公开目录可见的在岗、资格有效、至少在一家已核验营业门店有有效任职的牙医；不可见和不存在统一返回 404。读取时再次按公开条件过滤，资格或门店失效后不泄露内部医生资料。取消收藏允许清理已不再公开的旧记录。
- 列表按牙医编号游标分页，只有本人记录；`PUT` 同值不写第二条，改变来源只更新 `source`；`DELETE` 重复执行返回 204。
- 小程序医生名录登录后显示收藏与来源选择；未登录仍可浏览公开名录。请求结果不明时提示刷新收藏状态，不显示未证实的成功。
- 名录可分享某一位公开医生，分享路径只携带医生编号；接收人重新从公开目录读取，若医生已不符合展示条件便不显示。分享内容不带患者信息、收藏来源或内部资质证号。

隔离 PostgreSQL HTTP 测试覆盖两名用户隔离、同值重复、来源更新、未知字段、隐藏医生不可再收藏、旧收藏不展示和重复删除。小程序 API 单测覆盖分页及请求体。真实微信开发者工具编译和真机交互仍需验收；CLI 预览因开发者工具「服务端口」关闭未执行，不能把 CLI 退出码 0 视作编译通过。
