# 前台用户档案摘要（2026-11-20）

本功能为真实接口。前台在精确检索、现场核验并取得患者选择凭证后，可见本店用户档案摘要；建档时可选明确获知渠道。页面显示“未采集”而非替历史数据猜测渠道。

上次接诊医师取本店最新**已完成**的 `visit_record.dentist_id`，没有完成就诊时显示“暂无已完成就诊”；预约医生、当前主治医生不充当上次接诊医师。后端要求 `patients.lookup`、本店有效任职，以及本店预约业务关联或当前操作者未过期的选择记录。响应不含完整电话、病历正文及其他门店就诊事实，读取审计记录操作者与门店。

前台摘要只是辅助核对，不能取代线下身份核验。创建选择凭证和代预约的授权、幂等规则保持原契约。
