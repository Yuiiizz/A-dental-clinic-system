# 前台医生排班表与患者端文案（2026-11-23）

前台新增 `/frontdesk-schedule`，从现有 `/staff/booking` 读取其已授权门店的未来已发布排班，按门店、上海日期、上午/下午展示医生和班次。页面只读，不开放负责人排班配置。服务项目和“当前有可约时段”仅根据同一响应的 `availability` 展示；无时段时不声称已约满，预约仍须到预约工作台提交并由服务端再次校验。负责人原排班配置入口仍是 `/scheduling`。

患者端把主路径上的“真实预约”“确认提交真实预约”等技术性文案改为“预约挂号”“确认预约”；保留真实/演示模式切换及演示不写入后台的提示。公开门店、医生的旧“教学虚拟/教学虚构”显示词改为“示例”；以后导入的基础种子和门店扩充脚本也改用“示例”标识。此为展示文案与新种子的调整，**没有修改现有云端数据库记录**，历史记录中的原文需要另行受控核对后清理。已执行过的 SQL 不会因仓库文件变更而自动更新云端。

开发时尚未部署。2026-11-23 随后已完成网页镜像云端构建和重启；公网 `/frontdesk-schedule` 路由及排班表 JS 资源返回 HTTP 200。真实前台账号的登录、授权门店和班次显示仍待实际点按验收。小程序 1.0.2 已上传为开发版，患者端预约列表获用户真机反馈；不能将网页静态资源可访问等同于前台权限及数据验收。
