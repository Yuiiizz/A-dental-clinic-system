# 供应商档案：当前实现边界

2026-11-09 开始接入真实供应商主档。V001 已建 `supplier`，V018 只新增 `suppliers.manage` 权限。管理端 `/suppliers` 已连接列表、详情和建档接口；`/demo` 的采购验收、库存和折旧仍为本地演示。

- 角色：inventory、owner 获显式权限；每次请求还需当前账号有效、已完成强制改密、至少一个同角色门店 scope 与本人已核实任职、门店营业且已核验、实例恰有一个营业中的经营主体。
- 创建：录入法定名称、主体标识、资质文件位置及核验依据、资质有效期。有效期不得早于上海业务日期；`verified_by/verified_at` 取当前会话与服务器时钟。没有实际审核文件上传或电子签章，页面明确要求人工核实。
- 历史主档允许 `valid_to` 为空；列表和详情显示“未填写”，不能据此推定资质有效。创建成功后的同键同内容重放即使跨过有效期，也只返回现有档案；使用新键创建仍按当前日期检查有效期。
- 并发：`credit_code` 唯一约束拦截不同键重复建档；`operation_request` 使同键同内容只落一份档案。档案、幂等记录与最小审计摘要在同一事务提交或回滚。重放仍重新鉴权。
- 列表不返回资质依据全文；详情只向同权限员工返回。新建失败或网络结果不明时，页面保留原输入与幂等键，不自动重发。
- 在 2026-11-09 的供应商主档阶段，教学库只有 3 家虚拟供应商，没有采购或库存事实。后续 V019 教学种子已加入普通耗材、库位和已过账验收入库事实；仍没有供应商付款、应付款或设备资产闭环。详见 [普通耗材验收入库](procurement-inventory.md)。

V019 已独立实现普通耗材验收明细、批次库存、过账时供应商资质复核和并发入库；采购订单、应付款、付款、税务与已过账冲销仍属后续范围。现有 `asset` 表可供设备卡片使用，但不得把采购演示数据直接写入资产或折旧。
